2. Назначение приложения

Приложение показывает расписание молитв мечети Ар-Рохман, напоминает о молитвах, позволяет слушать Коран и вести счётчик зикра. Для обычного использования регистрация не требуется.

3. Какие данные обрабатываются

  • Данные администратора. Для входа в служебный раздел используется Firebase Authentication. Обрабатываются данные учётной записи администратора, включая адрес электронной почты. Обычным пользователям вход в этот раздел не нужен.
  • Уведомления. Firebase Cloud Messaging использует идентификаторы установки и push-токен для доставки сообщений об изменении расписания. Разрешение на показ уведомлений можно изменить в настройках Android.
  • Реклама. После разрешения рекламы Yandex Mobile Ads SDK может обрабатывать рекламный идентификатор устройства и технические данные для запроса, показа и оценки рекламы. Обработка выполняется Яндексом и компонентами его рекламного SDK, включая AppMetrica, в соответствии с документацией сервиса и применимыми настройками устройства. Геолокация в рекламный SDK приложением не передаётся.
  • Локальные настройки. Параметры уведомлений, счётчики зикра, избранные суры, решение о рекламе и сведения о скачанном аудио сохраняются на устройстве. Эти данные не отправляются разработчику для создания профиля пользователя.
  • Аудио. При прослушивании и скачивании сур выполняются запросы к аудиосерверу; при соединении сервер получает необходимые сетевые сведения, включая IP-адрес. Выбранный для азана локальный аудиофайл используется на устройстве и не загружается разработчику.
  • Обращения в поддержку. Если направлено письмо, обрабатываются адрес отправителя и сведения, добровольно включённые в обращение.

4. Выбор рекламы и обработка данных

При первом запуске версии с рекламой Яндекса предлагается выбор: разрешить обработку данных для показа рекламы или продолжить без рекламы. До разрешения и при отказе рекламные запросы не выполняются. Функции расписания, зикра и Корана остаются доступны.

Изменить решение можно в меню приложения «Реклама и конфиденциальность». При отказе загрузка рекламы прекращается. Отказ не удаляет автоматически сведения, которые были обработаны до изменения решения; для запросов об этих сведениях можно воспользоваться контактом выше и средствами соответствующего сервиса.

5. Сторонние сервисы

  • Firebase Authentication — вход администратора; Cloud Firestore — получение и хранение расписания; Firebase Cloud Messaging — доставка уведомлений. Сведения о конфиденциальности Firebase.
  • Yandex Mobile Ads и связанные компоненты — показ рекламы после разрешения. Политика конфиденциальности Яндекса; сведения о данных рекламного SDK.

6. Хранение, защита и удаление

Локальные настройки и скачанное приложением аудио можно удалить средствами приложения и Android. Удаление приложения или очистка его данных удаляет локальные данные в пределах действий, предусмотренных Android; самостоятельно сохранённые копии файлов могут оставаться отдельно.

Сроки обработки данных сторонними сервисами определяются их правилами и настройками. Соединения SDK Firebase и Яндекса защищаются при передаче. Для запроса доступа, исправления или удаления данных, относящихся к приложению, напишите на kirulbek@gmail.com и укажите характер запроса.

7. Изменения политики

Актуальная редакция размещается на этой странице. При изменении состава сервисов или обработки данных политика обновляется. Новое решение о рекламе можно принять в меню приложения независимо от обновления политики.
